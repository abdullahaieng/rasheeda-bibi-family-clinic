# Rasheeda Bibi Family Care Clinic

A modern, responsive web application for **Rasheeda Bibi Family Care Clinic**, featuring appointment booking integration, service details, and doctor background information for Dr. Ayesha Khalid Rao (Consultant Gynecologist).

* **Live Demo:** [rasheedabibclinic.vercel.app](https://rasheedabibclinic.vercel.app)
* **GitHub Repository:** [https://github.com/abdullahaieng/rasheeda-bibi-family-clinic](https://github.com/abdullahaieng/rasheeda-bibi-family-clinic)

---

## Key Features

* **Direct WhatsApp Integration:** Streamlined booking flow that pre-fills consultation request messages directly to WhatsApp.
* **Doctor Profile & Credentials:** Dedicated section highlighting clinical background, qualifications (M.B.B.S | D.G.O), and affiliated hospital details.
* **Services Showcase:** Clear overview of medical offerings including specialized ultrasound services.
* **Contact & Timings:** Instant access to phone details, operating hours, and booking CTAs.
